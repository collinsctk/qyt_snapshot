# CTK Snapshot

CTK Snapshot 是一款基于 **Python 3.9+** 与 **PyQt5** 打造的 Windows 桌面截图与标注工具，主打即装即用与桌面原生体验。它集成了区域截屏、批量导入、标注工作台、风格化调节、系统托盘、全局热键等完整工作流，适用于教程整理、产品文档、学习做笔记等日常图像整理需求。

## 功能亮点
- **完整截图链路**：支持区域截取、重复上次截取，亦可批量导入已有图片；截屏后即进入标注工作台。
- **丰富标注工具**：矩形框、顺序标记、颜色/线宽/圆角/填充调节、复制、删除、自动/手动保存与撤销操作，一应俱全。
- **风格化与辅助**：放大镜、遮罩层、坐标与尺寸提示帮助精确落点；标签页状态提示未保存内容。
- **全局热键与托盘**：通过 Win32 API 注册系统级热键，托盘菜单可快速切换模式或退出，后台常驻也能秒开。
- **配置持久化**：所有偏好项（保存目录、导出质量、热键等）写入 `config.json`，重启后自动恢复。
- **Windows 深度整合**：利用注册表管理开机自启、单实例互斥与系统光标管理，确保在 Windows 上获得顺畅体验。

## 目录速览
- `screenshot_tool.py`：应用入口，包含 UI、截图逻辑、标注组件、热键管理、配置读写等核心实现。
- `screenshots/`：默认截图与导出目录（首次运行自动创建，可在设置中修改）。
- `favicon/`：应用窗口与打包后 exe 使用的图标资源。
- `config.json`：运行时生成的配置文件，保存用户自定义项。
- `requirements.txt`：依赖清单，便于新环境快速安装。

## 环境部署
CTK Snapshot 目前仅支持 Windows 环境（依赖 `winreg`、`ctypes.windll` 等 Win32 API）。在 macOS 或 Linux 上会因缺少相关接口而无法运行，可选择在 Wine 中尝试。

1. 安装 Python 3.9 及以上版本，并确保加入 PATH。
2. 安装依赖：
   ```bash
   pip install -r requirements.txt
   ```
3. 启动应用：
   ```bash
   python screenshot_tool.py
   ```
程序启动后可直接选择“区域截图”“重复上次截取”或“导入图片”。截图与标注结果默认写入 `screenshots/`，也可在系统设置面板调整路径。

## 打包为 EXE（可选）
若需要分发给未安装 Python 的同事，可使用 PyInstaller：
```bash
pyinstaller --onefile --noconsole --icon=favicon/favicon.ico screenshot_tool.py
```
生成的可执行文件位于 `dist/` 目录，已带自定义图标。如需额外静态资源，可在 `screenshot_tool.spec` 中配置。

## 常见问题
- **热键注册失败**：确认组合未被其他程序占用，必要时以管理员身份运行。
- **配置无法保存**：检查项目目录写入权限，或修改保存路径至用户具有写权限的位置。
- **想要 macOS 支持？** 当前版本深度依赖 Win32 API，尚无跨平台实现，欢迎提交 Issue 讨论需求。
